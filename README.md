# Description
This project is a virtual reality game for players to experience riding a hand-powered tricycle around various environments.  
  
This game is intended to give those without the ability to ride a real bicycle or hand-bike a similar experience in VR.  
  
There are several game-modes and playable environments to choose from, with plans for each game-mode to be playable in every environment.  
  
Game-modes include:
1. Time Trial: The goal is to reach the end of the track in the shortest time possible
2. NPC Race: Players will race against computer-controller characters to finish first
3. Casual Mode: Players are free to explore the tracks at their leisure.
